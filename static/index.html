无线电频谱干扰调查与协调

使用 JSON API 创建干扰事件、记录来源、定位和执行处置动作。

GET  /health
GET  /api/state
GET  /api/items
GET  /api/items/{id}
POST /api/items
POST /api/items/{id}/sources      补录测量；同源(type+external_id)只留一条，观测更晚者为准，被替记录入审计
                                   更新已有来源需在请求体带 expected_version，并发冲突返回 409
POST /api/items/{id}/actions      assess / locate / suspend / coordinate / resolve / correct_measurement / delegate / cancel
GET  /api/items/{id}/audit

测量记录是事件基准的依据：基准随最新观测重算，评估等级自动重算；事件已定位或处置中时，基准变化会置 review_required 提示复核。跨区处置需对方协调人 delegate 代管授权，到期自动收回。
