无线电频谱干扰调查与协调

使用 JSON API 创建干扰事件、记录来源测量、定位和执行处置动作。

GET  /health
GET  /api/state
POST /api/items
POST /api/items/{id}/sources       # 同来源重复回传：更晚观测替换并留痕；更早/同时刻后到者拒绝
POST /api/items/{id}/actions       # assess/locate/suspend/coordinate/resolve/correct_measurement/acknowledge_review/cancel
GET  /api/items/{id}/audit
POST /api/delegations              # 代管授权（到期自动收回）
GET  /api/delegations

基准测量按观测更晚者作准；基准变化时已完成的评估失效并重算，已定位/处置中的事件出现复核提示（review_required）。
